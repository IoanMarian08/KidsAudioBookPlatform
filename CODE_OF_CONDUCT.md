# Code of Conduct

## Purpose

KidsAudioBookPlatform exists to make a safe, calm, inclusive listening product for children and families. The development community must reflect those values.

## Expected conduct

- Treat contributors, maintainers and users with respect regardless of background, identity, experience or ability.
- Discuss technical disagreements using evidence, concrete examples and attention to product/child safety.
- Give constructive feedback focused on code, documentation and user impact; allow others to correct mistakes.
- Protect secrets and personal information. Never share identifiable child data, private support details, private credentials or security exploits in public discussions.
- Follow repository contribution standards and keep discussions within project scope.

## Unacceptable conduct

Harassment, threats, targeted insults, discriminatory conduct, intimidation, doxxing, sexualized content directed at people, spam, malicious disruption or repeated ignoring of moderator requests are not acceptable.

## Reporting and enforcement

Report non-security conduct concerns privately to the repository owner/maintainers using an available private communication channel. Do **not** post sensitive reports as public issues. For vulnerabilities use [SECURITY.md](SECURITY.md). The owner should review reports confidentially, hear relevant perspectives and take proportionate steps: warning, content removal, temporary restriction or permanent exclusion as appropriate.

No specific private email or response deadline is represented as established until the owner publishes one.

## Scope

These guidelines cover issues, PRs, code review, documentation contributions and project-associated community channels.
