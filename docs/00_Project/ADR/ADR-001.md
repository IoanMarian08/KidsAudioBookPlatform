> **Historical decision — superseded.** This short early ADR is retained only as decision history. The active Flutter design is [ADR-0004-flutter-mobile-platform.md](ADR-0004-flutter-mobile-platform.md). Modern ADR-0004 specifies the current Flutter implementation model, native adapter boundaries and security rules. Do not implement from this legacy record.


## Context

The product must be available on both Android and iOS. The team is small and needs a single codebase to reduce development time while maintaining a high-quality mobile experience.

---

## Decision

Use Flutter as the main mobile framework for Android and iOS.

---

## Alternatives Considered

- Native Android + Native iOS
- React Native
- Flutter

---

## Consequences

- Single codebase
- Faster development
- Consistent UI
- Requires Flutter expertise
- iOS build still requires macOS/Xcode

---

## Notes

This decision may be revisited if product scale, team size or business constraints change.
